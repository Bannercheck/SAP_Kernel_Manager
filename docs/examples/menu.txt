skm — SAP Kernel Manager

   1) SAP Status       host, kernel, directories, instances and sapstartsrv state
   2) SAP Stop         stop the SAP system and wait until every instance is down   (planned: step 2)
   3) SAP Start        start sapstartsrv and the SAP system, wait until running   (planned: step 2)
   4) Kernel Backup    copy DIR_CT_RUN to exe_<timestamp> as <sid>adm:sapsys   (planned: step 3)
   5) Kernel Packages  import, verify and list SAPEXE/SAPEXEDB archives   (planned: step 4)
   6) Update Plan      preflight checks and an executable update plan   (planned: step 5)
   7) Kernel Update    run the plan: stop, backup, deploy, fix, start, verify   (planned: step 6)
   8) Kernel Rollback  restore the backup taken by a previous run   (planned: step 6)
   9) Run History      previous runs and their outcome   (planned: step 6)
  10) Health Check     tool paths, privileges, sapcontrol access   (planned: step 5)
  11) Version          build information
   q) Quit
